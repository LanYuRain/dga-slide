# 資工系期初系員大會 · 動態簡報（2026）

成品是根目錄的 `csie-assembly-2026.html`：單一檔案，家長日簡報 28 頁、字型子集、GSAP 都內嵌在裡面，斷網也能播放。

## 播放
- ← → / 空白鍵 / 點擊（左 30% 上一頁）/ 手機左右滑動，`F` 全螢幕，網址 `#n` 直接開第 n 頁
- 頒獎頁（第三名、第二名、第一名、特殊獎）：按 `1`–`4` 或點右下角按鈕揭曉小隊，`0` 清除。每次進入頒獎頁都會重新從「?」開始；緊接在後的獎品頁（雞排、健康步道）會帶入剛揭曉的小隊

## 檔案
| 檔案 | 用途 |
|---|---|
| `deck.html` | 模板：樣式、手寫頁面、引擎、轉場與場景。`@@…@@` 是預留位置 |
| `build.py` | 教授資料（`PROFS`）、產生引言卡／實驗室總覽／分組名單，並嵌入圖片、QR、字型與 GSAP |
| `vendor/gsap.min.js` | GSAP 3.13 |
| `.cache/` | 下載的字型、轉好的頁面圖（不進版控） |

## 重新產生
```bash
cd deck
uv venv && uv pip install -r requirements.txt   # 或 python -m venv + pip
.venv/bin/python build.py                        # 輸出 ../csie-assembly-2026.html
```
需要 `../docs/` 裡的三份素材：`115學年度新生家長日-final.pdf`、`分組名單.md`、`回饋表單qrcode.JPG`。
QR code 會被取樣成向量重畫；安裝了 `zxing-cpp` 時，建置會驗證重畫後的內容和原圖完全一致。

## 常見修改
- **教授資料**：改 `build.py` 的 `PROFS`，順序必須和家長日簡報頁序一致（個人頁 = 第 2k 頁）
- **分組名單**：直接改 `docs/分組名單.md` 後重建
- **其他頁面文字**：改 `deck.html`
