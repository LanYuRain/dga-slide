# 實作備忘

這裡只放「不注意就會出錯」的技術細節。設計手法、緩動、節奏、配色、字體——那些你本來就會，由你決定。

## 細微動態的上限（「靜止即完整」的具體定義）

靜止狀態允許的動態，以「不搶走閱讀注意力」為界：

| 屬性 | 上限 |
|---|---|
| 文字本體 | 不動（不位移、不閃爍、不跑馬燈） |
| 其他元素位移 | 約 ≤ 6px；大面積背景可更大，但要極慢 |
| 縮放 | 約 ≤ 1.5% |
| 透明度變化 | 約 ≤ 0.15 |
| 高對比的快速變化 | 不允許 |

背景可以有生命（流動的漸層、粒子、WebGL 場景、光暈呼吸），只要它安靜到讓人能專心讀字。

## 容易踩的坑

- **預設狀態 = 靜止狀態**：用 `from` / `fromTo` 讓元素抵達 CSS 狀態。引擎在轉場結束時會對 timeline 動過的元素 `clearProps: "all"`，所以「動畫終點 ≠ CSS」的地方會在結束瞬間跳一下——看到跳動就是這個原因。
- **SplitText**：要等字體載入後再拆（引擎已等待 `document.fonts.ready`）；拆完在 `Deck.onCleanup(() => split.revert())` 還原，靜止 DOM 才乾淨、可選取、可被翻譯。
- **數字滾動**：結束時必須顯示精確的原始文字（含千分位、小數、單位）；最穩的作法是 onComplete 直接把原字串寫回去。
- **CSS animation 與 GSAP 搶 transform**：同一個元素只用一種方式動 transform。細微動態若用 CSS keyframes，就不要再用 GSAP 動同一元素的 transform（或改用 `Deck.scene(...).idle`）。
- **往回翻**：轉場函式會收到 `dir = -1`，要讓倒退也合理（反向、鏡像或另一種）。
- **reduced-motion**：引擎會自動改用淡入淡出並停止 idle；WebGL／canvas 背景要自己檢查 `Deck.reduced` 並停下。
- **字級**：簡報要投影或在手機上看，1920 寬座標下內文大約不要小於 28px。
- **GSAP 外掛**：自 3.13 起全部免費，路徑為 `https://cdn.jsdelivr.net/npm/gsap@3.13.0/dist/<Plugin>.min.js`，載入後引擎會自動 register 常見外掛。
